# demodgm.github.io

Source for Efe Demir Degim's project portfolio: research, FRC robotics, ConPact and music.

Live site: https://demodgm.github.io/

Static HTML and CSS with no build step. `video.js` only swaps a poster for a YouTube (youtube-nocookie.com) player when the reader clicks; without JavaScript every poster is a plain link. Fonts (Source Serif 4, IBM Plex Mono; SIL Open Font License) are self-hosted in `fonts/`.
